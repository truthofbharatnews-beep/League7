NEXUS — Separate HTML page package

PUBLISHING
1. Extract this ZIP.
2. Upload ALL .html files plus style.css and script.js to the same website folder.
3. Publish that folder (for example, with GitHub Pages).
4. Open index.html. Navigation links open the separate HTML pages.

FILES
- index.html: Dashboard / home page
- feed.html, gallery.html, messages.html, games.html, servers.html
- teams.html, tournaments.html, leagues.html, leaderboard.html
- friends.html, notifications.html, profile.html, settings.html
- style.css and script.js: shared design and demo interactions

IMPORTANT
This is a static frontend demo. Demo posts, comments, profile settings, server messages and uploaded images are stored only in the current browser/device. They are NOT shared with other visitors. Real accounts, cross-device data, public image uploads, and live multiplayer chat require Firebase or another backend. No build tools or package installation are needed.

Keep every file in the same folder and preserve the filenames.
